# File 05 Backup and Restore Evidence Guide

A backup file existing is not restore proof.

The consistent recovery set includes WordPress database, File 05 plugin/versioned package, relevant configuration, independent private-note key material under secure key-management procedures, and companion versions needed to interpret contracts.

An isolated restore rehearsal must verify: table counts and representative hashes; core/state schema; post/meta/taxonomy relationships; private-note decryption for current and retained key generations; correction states; outbox/jobs; managed pages; cache/index rebuild; and guest/learner/teacher/reviewer workflows.

Keys/secrets and private incident procedures must not be committed to this public repository. This document describes evidence requirements only.
